## Overview

Blue Cat Re-Guitar shapes DI guitar signals into polished amp tones using impulse responses and a built-in EQ/saturation chain, perfect for re-amping without hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat Re-Guitar** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **IR Convolver** | Load any guitar cabinet impulse response for realistic tone |
| **Amp Stage** | Gain staging with adjustable clipping for preamp simulation |
| **EQ Section** | 4-band parametric EQ for post-cabinet tone shaping |
| **Direct Monitoring** | Zero-latency direct input monitoring mode for live playing |
